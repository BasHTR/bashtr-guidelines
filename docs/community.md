# Open Questions

The current guidelines do not yet define how reference marks should be recorded or how reading order should be represented in complex layouts. These matters will be reviewed as new manuscript evidence and community feedback become available.

Feedback is welcome on [BASHtr GitHub](https://github.com/BasHTR/bashtr-guidelines).
